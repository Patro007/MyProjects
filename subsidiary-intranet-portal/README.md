# Subsidiary Intranet Portal - Proof of Concept\n\nA comprehensive on-premise HR management platform consolidating multiple subsidiaries into a single unified portal.\n\n## 🎯 Features\n\n- **Multi-Department Management**: Support for 8-10 subsidiaries with independent configurations\n- **Employee Management**: Centralized employee master data across all departments\n- **Leave Tracking & Approval**: Complete leave management with multi-level approvals\n- **Attendance System**: Real-time attendance tracking and reporting\n- **Payroll Management**: Payslips, offer letters, resignation letters\n- **Performance KPI System**: Goal tracking and performance reviews\n- **Business Trip Tracking**: Trip requests, approvals, and expense tracking\n- **PF Management**: PF account details and contribution tracking\n- **Single Sign-On**: Keycloak-based OIDC/SAML authentication\n- **Reporting & Analytics**: Metabase integration for business intelligence\n- **File Storage**: MinIO for secure document storage\n\n## 🏗️ Architecture\n\n### Technology Stack\n\n| Layer | Technology | Purpose |\n|-------|-----------|----------|\n| **Frontend** | React.js + Material-UI | User interface |\n| **Backend** | Python + Django REST Framework | API & Business Logic |\n| **Database** | PostgreSQL + Redis | Data storage & caching |\n| **Authentication** | Keycloak | SSO & OIDC/SAML |\n| **File Storage** | MinIO | Document management |\n| **Monitoring** | Prometheus + Grafana | System monitoring |\n| **Orchestration** | Docker Compose | Container management |\n| **Reporting** | Metabase | BI & Analytics |\n\n### Modular Backend Structure\n\n```\nbackend/\n├── core/                    # Shared utilities, authentication\n│   ├── models.py           # Base models, audit trails\n│   ├── permissions.py      # RBAC and authorization\n│   ├── serializers.py      # Common serializers\n│   └── views.py            # Shared viewsets\n├── config/                 # Django settings and URLs\n│   ├── settings.py\n│   ├── urls.py\n│   └── wsgi.py\n├── departments/            # Department management\n│   ├── models.py           # Department, Subsidiary models\n│   ├── views.py\n│   ├── serializers.py\n│   └── urls.py\n├── employees/              # Employee master data\n│   ├── models.py           # Employee, designation, etc.\n│   ├── views.py\n│   ├── serializers.py\n│   └── urls.py\n├── leave_management/       # Leave tracking & approval\n│   ├── models.py           # Leave types, requests, approval workflows\n│   ├── views.py\n│   ├── serializers.py\n│   └── urls.py\n├── attendance/             # Attendance system\n│   ├── models.py           # Attendance records\n│   ├── views.py\n│   ├── serializers.py\n│   └── urls.py\n├── payroll/                # Payroll management\n│   ├── models.py           # Salary, payslips, components\n│   ├── views.py\n│   ├── serializers.py\n│   └── urls.py\n├── performance/            # Performance & KPI\n│   ├── models.py           # Goals, ratings, reviews\n│   ├── views.py\n│   ├── serializers.py\n│   └── urls.py\n├── business_trips/         # Trip tracking\n│   ├── models.py           # Trip requests, approvals\n│   ├── views.py\n│   ├── serializers.py\n│   └── urls.py\n└── pf_management/          # PF details\n    ├── models.py           # PF accounts, contributions\n    ├── views.py\n    ├── serializers.py\n    └── urls.py\n```\n\n## 🚀 Quick Start\n\n### Prerequisites\n- Docker & Docker Compose installed\n- Git\n- 4GB RAM minimum (8GB recommended)\n- Port availability: 80, 443, 5432, 6379, 9000, 3000, 9090, 3001, 3010\n\n### Installation\n\n1. **Clone Repository**\n   ```bash\n   git clone https://github.com/Patro007/MyProjects.git\n   cd MyProjects/subsidiary-intranet-portal\n   ```\n\n2. **Setup Environment**\n   ```bash\n   cp .env.example .env\n   # Edit .env with your configuration\n   ```\n\n3. **Start All Services**\n   ```bash\n   docker-compose up -d\n   ```\n\n4. **Initialize Database**\n   ```bash\n   docker-compose exec backend python manage.py migrate\n   docker-compose exec backend python manage.py createsuperuser\n   ```\n\n5. **Access Services**\n   - Frontend: http://localhost:3000\n   - Backend API: http://localhost:8000/api/\n   - API Documentation: http://localhost:8000/api/docs/\n   - Keycloak Admin: http://localhost:8080/auth/admin/\n   - Grafana: http://localhost:3001\n   - MinIO: http://localhost:9000\n\n### Logs\n\n```bash\n# View all logs\ndocker-compose logs -f\n\n# View specific service logs\ndocker-compose logs -f backend\ndocker-compose logs -f frontend\ndocker-compose logs -f keycloak\n```\n\n## 📊 Database Schema Overview\n\n### Core Tables\n\n#### Departments\n```sql\n- id (UUID)\n- name (String)\n- code (String, unique)\n- parent_department_id (FK)\n- location (String)\n- contact_email (String)\n- created_at\n- updated_at\n```\n\n#### Employees\n```sql\n- id (UUID)\n- employee_code (String, unique)\n- first_name (String)\n- last_name (String)\n- email (String)\n- phone (String)\n- department_id (FK)\n- designation_id (FK)\n- manager_id (FK, Employee)\n- date_of_joining (Date)\n- date_of_birth (Date)\n- status (active, inactive, on_leave)\n- created_at\n- updated_at\n```\n\n#### Leave Requests\n```sql\n- id (UUID)\n- employee_id (FK)\n- leave_type_id (FK)\n- from_date (Date)\n- to_date (Date)\n- reason (Text)\n- status (pending, approved, rejected, cancelled)\n- approver_id (FK, Employee)\n- approval_comment (Text)\n- created_at\n- updated_at\n```\n\n#### Attendance\n```sql\n- id (UUID)\n- employee_id (FK)\n- date (Date)\n- check_in_time (DateTime)\n- check_out_time (DateTime)\n- status (present, absent, half_day, work_from_home)\n- location (String)\n- created_at\n- updated_at\n```\n\n#### Payroll\n```sql\n- id (UUID)\n- employee_id (FK)\n- month (Date)\n- gross_salary (Decimal)\n- basic (Decimal)\n- da (Decimal)\n- hra (Decimal)\n- pf (Decimal)\n- tax (Decimal)\n- net_salary (Decimal)\n- status (draft, finalized, paid)\n- created_at\n- updated_at\n```\n\n#### Performance\n```sql\n- id (UUID)\n- employee_id (FK)\n- period_start (Date)\n- period_end (Date)\n- goal_description (Text)\n- rating (1-5)\n- reviewer_id (FK, Employee)\n- comments (Text)\n- created_at\n- updated_at\n```\n\n#### Business Trips\n```sql\n- id (UUID)\n- employee_id (FK)\n- destination (String)\n- purpose (Text)\n- from_date (Date)\n- to_date (Date)\n- status (requested, approved, rejected, completed)\n- approver_id (FK, Employee)\n- created_at\n- updated_at\n```\n\n#### PF Management\n```sql\n- id (UUID)\n- employee_id (FK)\n- pf_account_number (String)\n- opening_balance (Decimal)\n- current_balance (Decimal)\n- last_contribution_date (Date)\n- status (active, inactive)\n- created_at\n- updated_at\n```\n\n## 🔐 Authentication with Keycloak\n\n### Multi-Department SSO Setup\n\n1. **Create Keycloak Realm** per company or use single realm with multiple clients\n2. **Configure LDAP/Active Directory** integration (optional)\n3. **Create Client Applications** for frontend and backend\n4. **Set Role Mapping** for department access control\n5. **Configure SAML/OIDC** as required\n\n### Default Credentials (Dev Only)\n- **Keycloak Admin**: admin / admin\n- **Database**: postgres / postgres\n- **Django Admin**: superuser (created during setup)\n\n## 📡 API Documentation\n\nAPI documentation is available at: `http://localhost:8000/api/docs/`\n\n### API Endpoints Structure\n\n```\nGET    /api/departments/\nPOST /api/leaves/\nPOST   /api/leaves/\nGET    /api/leaves/{id}/\nPUT    /api/leaves/{id}/approve/\n\nGET    /api/attendance/\nPOST   /api/attendance/check-in/\nPOST   /api/attendance/check-out/\n\nGET /api/pf/details/\n```\n\n## 🛠️ Development\n\n### Adding a New Module\n\n1. Create app structure:\n   ```bash\n   docker-compose exec backend python manage.py startapp new_module\n   ```\n\n2. Define models in `models.py`\n3. Create serializers in `serializers.py`\n4. Create viewsets in `views.py`\n5. Register URLs in `urls.py`\n6. Register app in `settings.py`\n\n### Running Tests\n\n```bash\ndocker-compose exec backend python manage.py test\n```\n\n### Code Style\n\n```bash\n# Format code\ndocker-compose exec backend black .\n\n# Linting\ndocker-compose exec backend flake8 .\n```\n\n## 📈 Monitoring\n\n- **Prometheus**: http://localhost:9090\n- **Grafana**: http://localhost:3001 (admin / admin)\n- **Logs**: All services log to Docker\n\n## 🔄 Data Migration from Legacy Systems\n\nSee `migration/` directory for ETL scripts to migrate from:\n- Excel files (CSV import)\n- Existing databases (SQL scripts)\n- Legacy portals (API sync)\n\n## 📝 License\n\nThis project uses open-source components:\n- Django: BSD License\n- React: MIT License\n- PostgreSQL: PostgreSQL License\n- Keycloak: Apache 2.0\n- All other components: Check individual licenses\n\n## 🤝 Contributing\n\nFork the repository and submit pull requests for any improvements.\n\n## 📞 Support\n\nFor issues and questions, please create a GitHub issue.\n\n---\n\n**Built with ❤️ for distributed organizations**\n
